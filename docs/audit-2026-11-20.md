## 效能與相容性

同一份教材及錄音；以下是實際檔案位元組，不是手機網路計時。首次頁面只計 HTML 與它直接載入的 JS／CSS。gzip 為逐檔使用 Node 預設壓縮後相加；實站壓縮、快取及連線狀態可能不同。

| 指標（bytes） | v2.9.0 | v2.9.1 |
|---|---:|---:|
| index.html | 343,482 | 4,967 |
| 首次頁面未壓縮合計 | 782,953 | 489,827 |
| 逐檔 gzip 合計 | 268,549 | 181,822 |

- 945 個音訊目標的執行期索引現在是 67,933 bytes。校驗碼留在權威 manifest，毋須每支手機每次解析。正常版與慢速版仍是不同 MP3；沒有移除、替換或重新合成任何課程音檔。
- 筆記輸入合併 350 ms 內連續寫入；切換到背景／離頁會立即嘗試儲存。課程的句子按課索引，語音長文共用斷句器。保留 v1、v2 儲存鍵與教材 ID。
- 初載的腳本與樣式請求由 12 提為 18，以便分檔快取及獨立驗證；上表不表示 LCP、首次可互動時間或每一支手機均快相同比例。

## 驗證與維護

```bash
node tools/test_release.mjs
node tools/test_c1.mjs
node tools/test_more_content.mjs
node tools/test_audio_promotion.mjs
python tools/test_model_assets.py
```

測試涵蓋 12 個主要路由；舊進度、損壞檔、取消、寫入失敗、雙分頁與錄音權限延遲；正常／慢速選擇、私稿線上語音拒絕；5 組音庫共 1,890 個 MP3 與正式 manifest 的 SHA-256。另在本次發布環境用 FFmpeg 完整解碼全數課程檔。發布驗證另比對正式首頁、18 個入口資產、各音庫取樣共 30 支課程 MP3，以及 2 支獨立音效檔和診斷頁。

修改內容後：先執行 `node tools/build_audio_catalog.mjs --write`（音庫變更時），再 `node tools/check_entry_assets.mjs --write`，然後跑上述測試。正式站按原有 GitHub Pages 方式部署，不需要搬站。三個現行合成流程可在課程變動時自動執行，或在 main 手動啟動；遇到並行更新會拒絕直接覆寫，請重跑最新版本。

## 保留限制

- 這是公開靜態學習工具，沒有登入、雲端同步或用戶筆記加密。相同瀏覽器設定檔下，同源網頁有可能存取 localStorage；備份 JSON 亦是明文。訪客請用代號，不要輸入機密條件或個資。CSP/SRI 無法防止同時控制根 HTML 與程式的管理權限遭竄改。
- 變更未調整帳號權限或分支保護。仍依賴 GitHub／作業系統及間接套件；未做完整相依套件認證，也沒有在使用者的 iPhone／Android 實體揚聲器上做聲學測量。自訂 OS 線上語音另經同意，不屬於本站上傳錄音。
- 依據：[GitHub Actions 安全指引](https://docs.github.com/en/actions/reference/security/secure-use)、[子資源完整性](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Subresource_Integrity)、[Kokoro 模型原始發行](https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.1)。
