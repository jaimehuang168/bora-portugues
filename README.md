- 設計參考：[歐洲理事會 CEFR C1 整體能力描述](https://www.coe.int/en/web/common-european-framework-reference-languages/table-1-cefr-3.3-common-reference-levels-global-scale) 及 [CEFR Companion Volume](https://rm.coe.int/common-european-frameworkof-reference-for-languages-learning-teaching/16809ea0d4) 的語域調整與互動描述。這是選修難度，不是能力檢定。所有案例均為虛構練習，不是園區條件、採購決議、旅遊規定或時效資料。
- 驗證：`node tools/test_c1.mjs` 檢查所有固定播放文字在真實音庫中的兩個檔案、SHA-256 及慢速時長，同時檢查升級時舊進度可讀。`node tools/test_more_content.mjs` 可回歸檢查上一批教材。

## 單字與句子發音修復（v2.7.0）

- 為日課、字幕練習、文法例句與 36 個新詞條的固定教材補齊正常／慢速的巴西葡語 MP3。共盤點 371 段不重複教材文字，新增 334 段（668 個 MP3），其餘 37 段沿用既有音檔。兩種速度分開合成，不只是把同一段音檔變慢。
- 手機版固定教材不再依賴裝置的 pt-BR 系統語音。自訂的新文字仍須裝置提供 pt-BR 語音。Dora 音檔是神經合成示範，並非原影片聲音或真人錄音。
- 若網站內建 MP3 試聽也無聲，先檢查手機媒體音量、藍牙／車機輸出，改以 Safari 或 Chrome 開啟網站的獨立音效測試頁。本版沒有在使用者的實體手機揚聲器上驗證。

## 手機發音補救（v2.6.0）

- 日課、新增文法及新詞條的發音改用「有預製 MP3 時優先播音檔，其餘使用裝置 pt-BR 語音」。之前一律強制使用手機語音，連已經有 MP3 的詞也可能無聲。
- 各頁提供原生 MP3 試聽及故障分流；獨立 `audio-test.html` 不依賴手機的語音服務，可分辨媒體音量／瀏覽器播放問題與缺少巴葡語音的問題。

- 未更動使用者學習紀錄、音訊隱私設定或現有 MP3；本次未在實體 iPhone／Android 揚聲器上驗證。

## 會話中的文法、例句與詞彙

現有六組情境（咖啡館、搭車、展會招商、訪園、採購報價、投資跟催）共 18 輪，全部加入：

- 本輪核心文法：句型公式、繁體中文說明、對方說法拆解、建議回應與常見錯誤。
- 每輪恰好兩個葡中對照例句，共 36 個，另有可自行替換練習的提示。
- 每輪三個重點單字，共 54 個詞條：中文義、詞性、形式變化與使用說明。
- 相關字：明確標示同字族、近義、對照或其他語義關係，不把相關字全部當同義詞。
- 關聯字：情境中的常用搭配／片語，每個詞條各附一項相關字及一項搭配。
- 例句、核心單字、相關字和搭配都提供正常與慢速發音。

操作：聽力與口說 → 情境會話 → 作答。答對後，本輪「文法・2 個例句・3 個單字」會自動展開；作答前也可手動展開，但會提示將顯示建議回應。解析下方仍可按「繼續對話」。

首頁的「會話解析與單字」可直接閱讀六組情境，不必先測驗。「單字與關聯字」支援中文、葡文、詞性、搭配搜尋；葡文可不輸入重音符號。只閱讀解析不會自動標記會話完成。

部分文法規則有查核來源連結。例句與中文解說為原創教材；不是母語教師逐條審稿，也不是語言檢定。工作例句不構成園區價格、稅務或技術條件承諾。

## 正常與慢速發音

原有 222 句／444 個音檔保留；新增 197 段不重複的例句、單字與片語，共 394 個新 MP3。總音庫為 419 段文字／838 個正常與慢速音檔。

採用 Kokoro-82M `pf_dora` 巴西葡語神經合成音，非真人錄音、非使用者聲音複製。正常速度 1.0，慢速 0.75 為另外合成，不是把正常音檔直接拉慢。每檔單聲道 24 kHz／96 kbps，預留音量峰值餘裕及句首句尾留白。額外 0.6×／1.2× 選項仍會調整播放速度。

聲音來源選「推薦：固定教材用神經語音，自訂稿用系統」或「Dora 巴葡神經語音：固定教材」。已明確選「系統 pt-BR」者仍沿用裝置聲音；本次不擅自更改個人偏好。新增或修改的私人講稿仍由裝置的 pt-BR 語音處理，線上聲音使用原有同意流程，不擅自換成歐洲葡語。

保留逐句播放、重複、跟讀留白、正常／慢速下載、原生播放器及手機播放受阻時的手動重試。網站音檔按需載入，需要網路；無需 API Key。載入失敗不會退回舊 eSpeak 機械音。

原有聲音測試：https://jaimehuang168.github.io/bora-portugues/audio-test.html

新 394 個 MP3 全數通過波形非靜音、長度與完整解碼檢查；整合時再次比對全部新音檔 SHA-256。

165 項 Chromium 瀏覽器檢查通過：18 輪各兩例句／三單字、詞彙關係、全部顯示發音文字的音檔覆蓋、正常與獨立慢速實際播放、下載與暫停、中文／葡文搜尋、鍵盤展開、六組完整測驗流程、手機／平板／桌機版面、原生 localStorage 重新載入保存、原有計畫及路由、舊 Dora 發音回歸。音訊與儲存不是模擬介面。

這些檢查不代表 iPhone／Android 實機揚聲器、Safari 實機或母語教師審音已通過。合成音仍可能有專有名詞、短詞或韻律限制；請搭配老師練習。本版無 AI 發音評分、自由 AI 對話或雲端同步。

## 資料與隱私不變

未更改儲存鍵 `bora.ptbr.v2`、備份格式或原有學習資料。進度、老師資料、訪客卡與作品仍存在各自瀏覽器，不會上傳到 GitHub，也不會自動跨裝置同步。

生成音檔只使用本 App 公開教材，在建置機本地合成；未讀取個人講稿、錄音或客戶資料，沒有使用雲端 TTS API。網站未新增分析追蹤或麥克風權限要求。

換裝置或從舊本機 HTML 改用網站前，先匯出進度 JSON，再到新環境匯入；匯入是取代，不是合併。請勿把私人備份、客戶名單或帳號密碼放入公開儲存庫。網站沒有 Service Worker，不保證離線重開。
