# Bora! 巴西葡語練習室 v2.2.0

繁體中文介面、18 個月招商葡文計畫，固定教材改用 Dora 巴西葡語神經合成音。

## 手機開啟

練習網站：https://jaimehuang168.github.io/bora-portugues/?voice=2.2.0#home

正常／慢速獨立試聽：https://jaimehuang168.github.io/bora-portugues/audio-test.html?v=2.2.0

以 Safari／Chrome 開啟。首頁應顯示「清晰巴葡發音版 v2.2.0」，按「試聽清晰發音」。不要繼續開啟下載在電腦或手機的舊 v2.1.1 HTML。

聲音來源選「推薦：固定教材用神經語音，自訂稿用系統」或「Dora 巴葡神經語音：固定教材」。已明確選用「系統 pt-BR」的使用者仍會聽到其裝置聲音，可自行切換；本次更新不擅自改動個人偏好。

## 音質修正

- 原有 222 句固定教材全部重新生成，共 444 個 MP3：正常 1.0 與另外合成的慢速 0.75。慢速按鈕不再只是拉慢正常音檔。
- 採用 Kokoro-82M `pf_dora` 巴西葡語神經語音，非真人錄音、非使用者聲音複製。停止播放舊的 eSpeak 基礎音檔，音檔載入失敗也不會退回舊音色。
- 每檔為單聲道 24 kHz／96 kbps MP3，預留音量峰值餘裕、句首與句尾留白。
- 保留逐句播放、重複、留白跟讀、正常／慢速下載、原生播放器及手機播放受阻時的手動重試。
- 額外的 0.6×／1.2× 選項仍會調整播放器速度；標準慢速 0.75 使用專用音檔。

網站音檔按需載入，需要網路；不必安裝系統葡語聲音或輸入 API Key。網站不提供離線重開保證。自訂或修改後的講稿沒有預製音檔，仍使用裝置提供的 `pt-BR` 語音與原有同意流程，不會擅自改用歐洲葡語。

## 已完成的驗證與限制

444 個新 MP3 全數通過波形非靜音、檔案長度與完整解碼檢查；升級工具再次比對全數 SHA-256。

28 項 Chromium 手機尺寸瀏覽器檢查通過，包含實際新 MP3 播放、正常／慢速檔案選擇、慢速下載、暫停／繼續、連續播放、手機版面、原生 localStorage 重新載入保存與既有路由。這一輪音檔與儲存測試不是模擬介面。

上述驗證不代表 iPhone／Android 實機揚聲器、Safari 實機或母語教師逐句審音已通過。合成音仍可能有個別專有名詞、很短語句或韻律限制，應搭配老師示範；本版沒有 AI 發音評分。

## 資料不變

本次未更改儲存鍵 `bora.ptbr.v2`、備份格式或學習資料。不要為了更新聲音清除網站資料。

學習進度、老師資料、訪客卡與作品仍存在使用者自己的瀏覽器，不上傳至 GitHub，也不自動跨裝置同步。生成音檔只使用既有公開教材，未存取個人講稿、錄音或客戶資料。

換裝置或從舊本機 HTML 改用網站前，先匯出進度 JSON，再到新環境匯入；匯入是取代，不是合併。請勿把私人備份、客戶名單或帳號密碼放入公開儲存庫。
