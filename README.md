## 會話中的文法、例句與詞彙

現有六組情境（咖啡館、搭車、展會招商、訪園、採購報價、投資跟催）共 18 輪，全部加入：

- 本輪核心文法：句型公式、繁體中文說明、對方說法拆解、建議回應與常見錯誤。
- 每輪恰好兩個葡中對照例句，共 36 個，另有可自行替換練習的提示。
- 每輪三個重點單字，共 54 個詞條：中文義、詞性、形式變化與使用說明。
- 相關字：明確標示同字族、近義、對照或其他語義關係，不把相關字全部當同義詞。
- 關聯字：情境中的常用搭配／片語，每個詞條各附一項相關字及一項搭配。
- 例句、核心單字、相關字和搭配都提供正常與慢速發音。

操作：聽力與口說 → 情境會話 → 作答。答對後，本輪「文法・2 個例句・3 個單字」會自動展開；作答前也可手動展開，但會提示將顯示建議回應。解析下方仍可按「繼續對話」。

首頁的「會話解析與單字」可直接閱讀六組情境，不必先測驗。「單字與關聯字」支援中文、葡文、詞性、搭配搜尋；葡文可不輸入重音符號。只閱讀解析不會自動標記會話完成。

部分文法規則有查核來源連結。例句與中文解說為原創教材；不是母語教師逐條審稿，也不是語言檢定。工作例句不構成園區價格、稅務或技術條件承諾。

## 正常與慢速發音

原有 222 句／444 個音檔保留；新增 197 段不重複的例句、單字與片語，共 394 個新 MP3。總音庫為 419 段文字／838 個正常與慢速音檔。

採用 Kokoro-82M `pf_dora` 巴西葡語神經合成音，非真人錄音、非使用者聲音複製。正常速度 1.0，慢速 0.75 為另外合成，不是把正常音檔直接拉慢。每檔單聲道 24 kHz／96 kbps，預留音量峰值餘裕及句首句尾留白。額外 0.6×／1.2× 選項仍會調整播放速度。

聲音來源選「推薦：固定教材用神經語音，自訂稿用系統」或「Dora 巴葡神經語音：固定教材」。已明確選「系統 pt-BR」者仍沿用裝置聲音；本次不擅自更改個人偏好。新增或修改的私人講稿仍由裝置的 pt-BR 語音處理，線上聲音使用原有同意流程，不擅自換成歐洲葡語。

保留逐句播放、重複、跟讀留白、正常／慢速下載、原生播放器及手機播放受阻時的手動重試。網站音檔按需載入，需要網路；無需 API Key。載入失敗不會退回舊 eSpeak 機械音。

原有聲音測試：https://jaimehuang168.github.io/bora-portugues/audio-test.html

## 資料與隱私不變

未更改儲存鍵 `bora.ptbr.v2`、備份格式或原有學習資料。進度、老師資料、訪客卡與作品仍存在各自瀏覽器，不會上傳到 GitHub，也不會自動跨裝置同步。

生成音檔只使用本 App 公開教材，在建置機本地合成；未讀取個人講稿、錄音或客戶資料，沒有使用雲端 TTS API。網站未新增分析追蹤或麥克風權限要求。

換裝置或從舊本機 HTML 改用網站前，先匯出進度 JSON，再到新環境匯入；匯入是取代，不是合併。請勿把私人備份、客戶名單或帳號密碼放入公開儲存庫。網站沒有 Service Worker，不保證離線重開。

## 檔案與紀錄

- `index.html`：原有 App 與新的會話解析入口。
- `assets/conversation-content.json`：可讀的完整新教材；同名 JS 載入教材。
- `assets/conversation-learning.js`／`.css`：會話解析、單字搜尋與響應式版面。
- `assets/conversation-audio.js`：新音庫索引，與原有 Dora 音庫合併。
- `audio/conversation-manifest.json`、`audio/conversation-v1/`：197 段新文字及 394 個音檔／校驗碼。
- `conversation-generation-report.json`：教材與生成音檔檢查。
- `conversation-release-report.json`：版本、整合來源與網站檔案校驗碼。
- `conversation-browser-tests.json`：165 項瀏覽器檢查與限制。
- `audio/natural-manifest.json`、`audio/natural-v1/`：原有 222 句及 444 個 Dora 音檔。
- `AUDIO_CREDITS.md`：既有模型、聲音來源與授權資訊；新音檔使用相同模型與授權。
- `audio-quality-report.json`、`audio-browser-tests.json` 與舊 `audio-fix-report.json` 是前版歷史紀錄，不是目前 v2.3 發布報告。

整合工具有來源版本保護，請勿直接在未知版本重跑。生成教材的 gzip/base64 分段只是可驗證的靜態資料，不會以 eval／exec 執行；可讀版本在 `assets/conversation-content.json`。
